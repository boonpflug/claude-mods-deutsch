# fortschritt

Ein Claude-Code-Mod, der über dem Prompt live zeigt, woran Claude gerade arbeitet: wie lange der Durchgang schon läuft, wie viele Tool-Calls es gab und, wenn Claude Helfer-Agenten startet, jeden Helfer mit Aufgabe, Modell und Status. Praktisch für lange Aufgaben, bei denen mehrere Subagents parallel arbeiten.

## Installieren

Im Terminal in Claude Code eintippen:

```
/plugin install fortschritt --marketplace boonpflug/claude-mods-deutsch
```

Danach `y` zum Hinzufügen des Marketplace und mit Enter den Bereich „user“ wählen. Der Mod läuft sofort.

Aus der Shell geht es auch: `claude plugin install fortschritt --marketplace boonpflug/claude-mods-deutsch`
