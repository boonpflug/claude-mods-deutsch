# dateibaum

Ein Claude-Code-Mod, der rechts neben dem Chat ein Datei-Panel öffnet. Jede Datei, die Claude liest, erscheint dort mit einem Auge, jede Datei, die gerade bearbeitet wird, ist markiert, und fertig geänderte Dateien werden grün mit einem Haken. So siehst du jederzeit auf einen Blick, was Claude in deinem Projekt anfasst, ohne die Chat-Antworten durchlesen zu müssen. Öffnen mit /dateibaum.

## Installieren

Im Terminal in Claude Code eintippen:

```
/plugin install dateibaum --marketplace boonpflug/claude-mods-deutsch
```

Danach `y` zum Hinzufügen des Marketplace und mit Enter den Bereich „user“ wählen. Der Mod läuft sofort.

Aus der Shell geht es auch: `claude plugin install dateibaum --marketplace boonpflug/claude-mods-deutsch`
