# regel-merken

Ein Claude-Code-Mod für dauerhaftes Lernen aus Feedback. Wenn du Claude korrigierst, etwa mit „nein“, „sieht nicht gut aus“ oder „mach das lieber so“, erscheint über dem Prompt ein kleines Banner mit der Frage, ob daraus eine feste Regel werden soll. Ein Klick auf Speichern, und der Mod formuliert die Regel kurz und schreibt sie in deine CLAUDE.md, damit Claude denselben Fehler nicht noch einmal macht.

## Installieren

Im Terminal in Claude Code eintippen:

```
/plugin install regel-merken --marketplace boonpflug/claude-mods-deutsch
```

Danach `y` zum Hinzufügen des Marketplace und mit Enter den Bereich „user“ wählen. Der Mod läuft sofort.

Aus der Shell geht es auch: `claude plugin install regel-merken --marketplace boonpflug/claude-mods-deutsch`
