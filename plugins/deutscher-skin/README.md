# deutscher-skin

Ein Claude-Code-Mod, der nur die Darstellung ändert: Jeder Tool-Aufruf bekommt ein eigenes Icon und eine Farbe aus deiner Palette, Dateien werden hervorgehoben, Befehle erscheinen wie in einem eigenen Terminal-Theme. Dein Workflow bleibt exakt gleich, Claude Code sieht nur nach dir aus. Ein sicherer erster Mod zum Ausprobieren.

## Installieren

Im Terminal in Claude Code eintippen:

```
/plugin install deutscher-skin --marketplace boonpflug/claude-mods-deutsch
```

Danach `y` zum Hinzufügen des Marketplace und mit Enter den Bereich „user“ wählen. Der Mod läuft sofort.

Aus der Shell geht es auch: `claude plugin install deutscher-skin --marketplace boonpflug/claude-mods-deutsch`
