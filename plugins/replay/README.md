# replay

Ein Claude-Code-Mod, der jede Datei-Änderung eines Durchgangs mitschreibt. Mit /replay öffnet sich ein Panel, in dem du Änderung für Änderung durchgehst: welche Datei, was entfernt und was hinzugefügt wurde. Funktioniert für Code genauso wie für Texte, etwa einen Artikel-Entwurf, bei dem du genau sehen willst, wo Claude etwas umgeschrieben hat.

## Installieren

Im Terminal in Claude Code eintippen:

```
/plugin install replay --marketplace boonpflug/claude-mods-deutsch
```

Danach `y` zum Hinzufügen des Marketplace und mit Enter den Bereich „user“ wählen. Der Mod läuft sofort.

Aus der Shell geht es auch: `claude plugin install replay --marketplace boonpflug/claude-mods-deutsch`
