# merk-dir-das

Ein Claude-Code-Mod, der nach jeder längeren Antwort einen kleinen Zweit-Agenten (Haiku) drüberlesen lässt. Steht darin etwas, das du nicht überlesen solltest, etwa Kosten, Risiken, Fristen oder etwas, das du selbst tun musst, erscheint es als Hinweis über dem Prompt. Achtung: Der Zweit-Agent verbraucht zusätzliche Tokens.

## Installieren

Im Terminal in Claude Code eintippen:

```
/plugin install merk-dir-das --marketplace boonpflug/claude-mods-deutsch
```

Danach `y` zum Hinzufügen des Marketplace und mit Enter den Bereich „user“ wählen. Der Mod läuft sofort.

Aus der Shell geht es auch: `claude plugin install merk-dir-das --marketplace boonpflug/claude-mods-deutsch`
